# 安装与操作

1. 从 Releases 下载 `Starlight-TV-1.1.2-local-armeabi-v7a.apk`，通过 U 盘或电视允许的安装方式安装。此版本无需注册 MDBList 或填写 API Key。
2. 已安装旧「LibreTV 电视版」时直接覆盖安装。不要先卸载或清除数据。
3. 从电视应用列表打开「星幕 TV」，等待首次解包、导入片单和海报，再启动本地服务。请预留至少 1 GiB 可用空间。

电影：方向键选择海报，确认进入选集，来源旁显示测速结果；选择“使用最快来源”可切换。

播放：左右快进/快退，下键打开操作面板，确认选择倍速；返回退出播放。

直播：上下换台，左右换备用线路；返回回到频道列表，再返回回首页。

缓存：顶部“本地缓存”查看数量与占用。本地版不自动联网补充推荐或海报，评分以所标注的日期为准。来源检查、搜索、测速和播放仍需要网络。

退出：首页返回退出应用，或按 Home 离开；后台约 30 秒后服务停止。重新打开会自动启动服务。

新安装已带公开片单和海报快照，不带发布者的 Key、密码、观看记录或私人配置。片单数量与日期见发布页和数据清单；本地数据不保证每部片的外部播放源持续可用。

需要自动联网补充推荐的用户可保留 1.1.1。不要为切回旧版本而直接卸载应用，否则会清除本机数据。
