# 安装与操作

1. 从 Releases 下载 `Starlight-TV-1.1.1-armeabi-v7a.apk`，通过 U 盘或电视允许的安装方式安装。
2. 已安装旧「LibreTV 电视版」时直接覆盖安装。不要先卸载或清除数据。
3. 从电视应用列表打开「星幕 TV」，等待首次解包和本地服务启动。

电影：方向键选择海报，确认进入选集，来源旁显示测速结果；选择“使用最快来源”可切换。

播放：左右快进/快退，下键打开操作面板，确认选择倍速；返回退出播放。

直播：上下换台，左右换备用线路；返回回到频道列表，再返回回首页。

缓存：顶部“本地缓存”查看数量与占用。空闲浏览时自动补充，播放时暂停。推荐和海报可从本机读取，首次来源检查、搜索和播放仍需要网络。

退出：首页返回退出应用，或按 Home 离开；后台约 30 秒后服务停止。重新打开会自动启动服务。

新安装不会带入其他人的缓存或 MDBList Key。测试设备已经预热的条目数，不代表新安装时立即拥有这些条目。
